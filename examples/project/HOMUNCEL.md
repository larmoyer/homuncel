# Project instructions for Homuncel

Keep answers short. Prefer tools over speculation.

## Repo conventions

- Match existing package style; small, focused diffs.
- Do not commit secrets (`.env`, tokens, credentials).
- Run the project’s usual checks before claiming a fix is done.

## When stuck

- Search the repo before inventing APIs.
- If a command needs elevated privileges, stop and ask — do not invent sudo loops.
