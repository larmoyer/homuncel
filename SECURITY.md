# Security Policy

## Supported versions

Use the latest Homuncel release from the [installer](https://homuncel.netlify.app/docs/getting-started/install) or [changelog](https://homuncel.netlify.app/docs/reference/changelog).

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Report privately using GitHub’s private vulnerability reporting:

→ [Report a vulnerability](https://github.com/larmoyer/homuncel/security/advisories/new)

That channel reaches the maintainer privately; the report is not a public issue.

Include, when possible:

- Homuncel version (`homuncel --version`)
- OS and install method
- Steps to reproduce
- Impact assessment

We will acknowledge serious reports and coordinate disclosure.
