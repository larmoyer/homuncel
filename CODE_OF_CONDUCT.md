# Code of Conduct

## Our pledge

We want Homuncel’s public spaces (issues, discussions, private reports) to be welcoming and constructive.

## Expected behavior

- Be respectful and assume good intent
- Stay on topic; prefer docs links over wall-of-text dumps
- Do not share others’ private data, API keys, or confidential transcripts
- No harassment, hate speech, or spam

## Unacceptable behavior

Harassment, doxxing, sustained disruption, or posting malware / exploit instructions aimed at harming others.

## Enforcement

Maintainers may edit or remove content, lock threads, or block accounts that violate this policy. Report concerns via [private contact](CONTACT.md).
