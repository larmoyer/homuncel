## Before opening an issue

1. Confirm you are on a current binary (`homuncel --version`).
2. Search [existing issues](https://github.com/larmoyer/homuncel/issues) and [discussions](https://github.com/larmoyer/homuncel/discussions).
3. Redact API keys, tokens, and session contents from logs.

See [CONTRIBUTING.md](CONTRIBUTING.md) for what this repository accepts.
