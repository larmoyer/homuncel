# Contributing

Thank you for caring about Homuncel.

## What this repo accepts

This is the **public product / community** repository (issues, discussions, examples, license). Useful contributions here include:

- Clear bug reports and reproducible technical issues
- Feature requests with use cases
- Discussion participation (questions, ideas, show and tell)
- Corrections to docs linked from [homuncel.netlify.app](https://homuncel.netlify.app/) (open an issue describing the fix; maintainers update the docs site)
- Example configs, skills, or workflows shared in **Show and tell** (no secrets)

## What we do not accept

- Redistribution of the Homuncel binary in this repository
- Issues that paste live API keys or private transcripts

## Bugs & technical problems

Use the issue templates. Include:

- `homuncel --version`
- OS / install method
- Minimal steps to reproduce
- Expected vs actual behavior
- Relevant logs with secrets redacted

## Features

Open a **Feature request** issue, or start an **Ideas** discussion if you want early feedback from others.

## Code of conduct

Be respectful. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## License

By participating, you agree that feedback and examples you submit may be used to improve Homuncel. The Homuncel binary remains under [LICENSE.md](LICENSE.md).
