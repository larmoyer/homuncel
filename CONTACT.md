# Private contact

You can reach the Homuncel maintainer **privately through GitHub**.

## Confidential / private topics

Use GitHub’s **private vulnerability reporting** form (visible only to maintainers):

**[Send a private message](https://github.com/larmoyer/homuncel/security/advisories/new)**

Use this for:

- Security vulnerabilities (preferred)
- Confidential product or licensing questions
- Anything you do not want on a public issue or discussion

In the advisory title/body, say clearly if the topic is **not** a security bug (for example “Private: licensing question”). Maintainers still receive it privately.

## Public channels (prefer these when possible)

| Topic | Where |
|------|--------|
| How do I…? | [Discussions → Q&A](https://github.com/larmoyer/homuncel/discussions/categories/q-a) |
| Feature ideas | [Discussions → Ideas](https://github.com/larmoyer/homuncel/discussions/categories/ideas) |
| Bugs / breakage | [Issues](https://github.com/larmoyer/homuncel/issues/new/choose) |
| Show your setup | [Discussions → Show and tell](https://github.com/larmoyer/homuncel/discussions/categories/show-and-tell) |
